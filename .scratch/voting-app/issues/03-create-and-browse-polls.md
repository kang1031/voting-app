# 03: 운영자가 투표를 만들고 누구나 목록과 상세 화면을 본다

**What to build:** 운영자가 `/admin`에서 투표를 만들면, 누구나 메인 화면 목록에서 그 투표를 찾아 `/polls/[id]`에서 질문과 선택지를 볼 수 있다. 표를 던지는 기능은 아직 없다.

- 투표 만들기 폼: 질문, 선택지 2~10개(추가·제거 가능), 마감 시각(선택 사항)을 입력한다.
- 마감 시각은 브라우저 로컬 시간대로 입력받고, 브라우저에서 UTC로 바꿔 서버로 보낸다. 표시할 때도 브라우저 시간대로 보여준다.
- `투표 규칙` 모듈에 넣을 것:
  - **투표 생성 입력 검증**: 앞뒤 공백을 잘라낸 뒤 질문은 1~200자, 선택지는 2~10개에 각 1~100자여야 하고, 중복 선택지는 허용하지 않으며, 마감이 현재 시각보다 과거면 거부한다. 결과로 정리된 입력 또는 필드별 오류 목록을 돌려준다.
  - **마감 여부 판정**: 마감이 없으면 계속 진행 중이고, 마감 시각이 되는 순간부터 마감됨이다.
- 서버에서도 반드시 같은 검증을 거친다. 폼의 검증만 믿지 않는다.
- 투표는 만든 뒤 수정할 수 없으므로 수정 화면은 만들지 않는다.
- 메인 화면은 "진행 중"과 "마감됨" 두 구역으로 나누고, 각 구역은 최신순으로 정렬한다. 페이지 나눔은 없다. 투표가 없으면 빈 상태 안내를 보여준다.
- 투표 상세 화면(`/polls/[id]`)은 질문, 선택지, 마감 시각(있으면), 마감 여부를 보여준다. 없는 ID나 잘못된 형식의 ID는 404다.
- 화면 문구는 한국어로 쓰고, Tailwind만 사용하며, 모바일 화면을 지원한다.

- [x] 로그인한 운영자만 투표를 만들 수 있다(서버 액션이 세션을 검사한다)
- [x] 유효한 입력으로 만든 투표가 메인 화면의 "진행 중" 구역 맨 위에 나타난다
- [x] 잘못된 입력(선택지 1개, 11개, 빈 선택지, 중복 선택지, 201자 질문, 과거 마감)은 필드별 한국어 오류와 함께 거부된다
- [x] 마감 시각이 지난 투표는 "마감됨" 구역에 나타난다
- [x] `/polls/[id]`가 질문과 선택지를 입력한 순서대로 보여준다
