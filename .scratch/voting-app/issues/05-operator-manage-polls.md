# 05: 운영자가 결과를 보고, 조기 마감하고, 삭제한다

**What to build:** 운영자가 `/admin`에서 모든 투표의 결과를 투표 여부와 상관없이 보고, 진행 중인 투표를 지금 바로 마감하거나, 투표를 완전히 삭제할 수 있다.

- `/admin` 목록: 모든 투표를 "진행 중"과 "마감됨"으로 나눠 최신순으로 보여주고, 각 투표의 총 표 수와 결과(04의 결과 표시 부분을 재사용)를 보여준다.
- **조기 마감**: 진행 중인 투표에 "지금 마감" 버튼을 둔다. 마감 시각을 현재로 앞당기기만 하고 연장은 하지 않는다. 마감이 없던 투표에도 쓸 수 있다.
  - `투표 규칙` 모듈에 **조기 마감 계산**을 넣는다. 현재 마감과 현재 시각을 받아 새 마감을 돌려주고, 이미 마감된 투표라면 그대로 둔다.
- **삭제**: "정말 삭제할까요? 선택지와 모든 표가 함께 사라지며 되돌릴 수 없습니다."라는 확인 창을 거쳐 완전히 삭제한다(cascade). 삭제된 투표의 링크는 404가 된다.
- 조기 마감과 삭제를 처리하는 서버 액션은 모두 운영자 세션을 검사한다.

**Blocked by:** 04 (투표자가 투표하고 결과를 본다)

**Status:** ready-for-agent

- [x] 운영자는 투표하지 않았어도 `/admin`에서 모든 투표의 결과와 총 표 수를 본다
- [x] "지금 마감"을 누르면 그 투표가 메인 화면과 `/admin`에서 "마감됨"으로 옮겨지고, 이후 제출은 "마감된 투표입니다"로 거부된다
- [x] 이미 마감된 투표에는 "지금 마감" 버튼이 없다
- [ ] 삭제 확인 창에서 취소하면 아무것도 바뀌지 않는다 (브라우저에서 수동 확인 필요)
- [x] 삭제하면 투표가 모든 목록에서 사라지고, `/polls/[id]`는 404가 되며, DB에 그 투표의 선택지와 표가 남지 않는다
