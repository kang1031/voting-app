# 02: 운영자 로그인·로그아웃

**What to build:** 운영자가 비밀번호로 로그인해 운영자 화면에 들어가고 로그아웃할 수 있다. 로그인하지 않은 사람은 운영자 화면에 들어갈 수 없다.

- 운영자는 한 명이다. 비밀번호는 환경변수 `ADMIN_PASSWORD` 하나이고, DB에는 운영자 정보를 저장하지 않는다.
- `/admin/login`에서 로그인에 성공하면 `SESSION_SECRET`으로 서명한 세션 쿠키를 발급한다. `httpOnly`로 설정하고 7일간 유지한다.
- 로그인하지 않은 채 `/admin` 아래에 접근하면 `/admin/login`으로 보낸다. 서버 액션도 세션을 검사한다.
- `/admin`에는 일단 "운영자 화면" 자리표시와 로그아웃 버튼만 둔다.
- 로그인 실패 횟수는 제한하지 않는다.
- 이 버전의 Next.js는 규약이 바뀌었을 수 있으므로, 쿠키·리다이렉트·라우트 보호 방식은 `node_modules/next/dist/docs/`의 문서를 먼저 확인한다.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 틀린 비밀번호를 넣으면 "비밀번호가 올바르지 않습니다"라는 안내가 나오고 세션이 발급되지 않는다
- [ ] 맞는 비밀번호를 넣으면 `/admin`으로 이동한다
- [ ] 로그인하지 않은 상태로 `/admin`에 접근하면 `/admin/login`으로 이동한다
- [ ] 세션 쿠키를 조작하면(서명 불일치) 로그인하지 않은 것으로 처리된다
- [ ] 로그아웃하면 다시 `/admin`에 접근할 수 없다
- [ ] 비밀번호와 세션 비밀값이 클라이언트 번들에 포함되지 않는다
