# 04: 투표자가 투표하고 결과를 본다

**What to build:** 투표자가 투표 상세 화면에서 선택지 하나를 골라 확인하면 표가 저장되고, 곧바로 결과를 본다. 같은 브라우저로는 한 투표에 한 표만 던질 수 있다. 마감된 투표는 투표하지 않은 사람에게도 결과를 보여준다.

- 투표자 식별(ADR-0001): 처음 표를 던질 때 무작위 익명 ID를 `httpOnly` 쿠키로 발급해 1년간 유지한다. 투표하지 않은 방문자에게는 쿠키를 발급하지 않는다. 운영자 세션과는 서로 별개다.
- 표를 던지기 전에 "선택 후에는 바꿀 수 없습니다. '○○'에 투표할까요?"라는 확인 창을 띄운다.
- 표는 바꾸거나 취소할 수 없다.
- `투표 규칙` 모듈에 넣을 것:
  - **표 제출 판정**: 투표 상태, 이 투표자가 이미 표를 던졌는지, 고른 선택지가 그 투표의 것인지, 현재 시각을 받아 허용 또는 거부 사유(마감됨, 이미 투표함, 없는 선택지)를 돌려준다.
  - **결과 공개 여부 판정**: 보는 사람(운영자 또는 투표자), 표를 던졌는지, 마감 여부를 받아 보임 또는 숨김을 돌려준다. 운영자는 항상 볼 수 있고, 투표자는 투표한 뒤나 마감된 뒤에 볼 수 있다.
  - **결과 계산**: 선택지별 표 수와 내가 고른 선택지를 받아 선택지별 표 수, 비율, 강조 여부, 총 표 수를 돌려준다. 표가 0개면 모든 비율은 0%다.
- 마감 여부는 표를 저장하는 순간 서버에서 판정한다.
- 경계 상황:
  - 화면을 열어둔 사이 마감된 뒤 제출하면 "마감된 투표입니다"라고 안내하고 결과를 보여준다.
  - 이미 투표했거나 두 탭에서 동시에 제출하면 DB 유일 제약 위반을 "이미 투표했습니다"로 바꿔 보여주고 결과를 보여준다.
  - 화면을 열어둔 사이 삭제된 투표에 제출하면 "삭제된 투표입니다"라고 안내하고 목록으로 보낸다.
- 결과 화면: 선택지마다 표 수, 비율(%), 가로 막대를 보여주고, 내가 고른 선택지를 강조한다. 총 표 수도 보여준다. 새로고침해야 갱신된다. 이 결과 표시 부분은 05에서 운영자 화면이 재사용할 수 있게 만든다.
- 투표자에게 결과가 숨겨진 상태라면, 서버가 결과 데이터 자체를 내려보내지 않는다.

**Blocked by:** 03 (운영자가 투표를 만들고 누구나 목록과 상세 화면을 본다)

**Status:** ready-for-agent

- [ ] 투표하기 전에는 결과가 보이지 않고, 페이지 응답에도 표 수가 포함되지 않는다
- [ ] 확인 창에서 취소하면 표가 저장되지 않는다
- [ ] 투표한 뒤 결과가 보이고, 내가 고른 선택지가 강조된다
- [ ] 같은 브라우저로 다시 방문하면 투표 폼 대신 결과가 보인다
- [ ] 다른 브라우저(또는 시크릿 창)로는 따로 한 번 더 투표할 수 있다(의도한 동작)
- [ ] 마감된 투표는 투표하지 않았어도 결과가 보이고 투표 폼은 없다
- [ ] 마감 후 제출, 중복 제출, 삭제된 투표에 제출하는 경우가 각각 위의 한국어 안내대로 처리된다
- [ ] **표 제출 판정**, **결과 공개 여부 판정**, **결과 계산**의 단위 테스트가 있다(표 0개, 한 선택지만 표가 있는 경우, 마감 시각과 같은 순간에 제출하는 경우 포함)
