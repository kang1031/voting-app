# 트리아지 라벨

스킬들은 다섯 가지 표준 트리아지 역할로 말한다. 이 파일은 그 역할들을 이 저장소의 이슈 트래커에서 실제로 쓰는 라벨 문자열에 대응시킨다.

| mattpocock/skills의 라벨 | 우리 트래커의 라벨  | 의미                                         |
| ------------------------ | ------------------- | -------------------------------------------- |
| `needs-triage`           | `needs-triage`      | 관리자가 이 이슈를 검토해야 함               |
| `needs-info`             | `needs-info`        | 보고자에게 추가 정보를 기다리는 중           |
| `ready-for-agent`        | `ready-for-agent`   | 명세가 완전해서 사람 없이 에이전트가 처리 가능 |
| `ready-for-human`        | `ready-for-human`   | 사람이 직접 구현해야 함                      |
| `wontfix`                | `wontfix`           | 처리하지 않음                                |

스킬이 어떤 역할을 언급하면(예: "에이전트 처리 가능 라벨을 붙여라"), 이 표에서 대응하는 라벨 문자열을 사용한다.

실제로 쓰는 라벨 이름에 맞게 오른쪽 열을 수정하면 된다.
